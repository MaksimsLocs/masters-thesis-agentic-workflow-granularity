# masters-thesis-agentic-workflow-granularity
Anonymised n8n workflow versions and workflow granularity variants used in the master’s thesis “Selection Guidelines of Activity Granularity in Development of Agentic Workflows”.

## Repository contents

This repository contains anonymised n8n workflow JSON files used in the master's thesis.

The repository includes:
- historical Weekly Sales Planner workflow versions from v1.0 to v1.7;
- the coarse workflow variant;
- the selectively decomposed workflow variant;
- the micro granularity workflow variant.

Sensitive operational data has been removed or anonymised. The repository does not include raw licence plate values, event identifiers, candidate strings, API credentials, webhook URLs, or other confidential operational identifiers.
